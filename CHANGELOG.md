# Changelog

## [1.6] - Seek bar

**Features**

- Adds a seek bar. You can set the buttons and seek bar separately: on hover, always, or never.
- Under Playback, you can set the seek bar height (2 px by default) and show or hide the italic time readout above it.
- Centers the playback buttons below the artwork and gives them more room.
- Adds a Font option to italicize both the track title and artist.

**Fixes**

- Restores the widget's right-click menu.
- Fixes blank album covers with software rendering ( square corners there ).

## [1.5] - Audio visualizer

Adds an optional audio visualizer ( bars only ), minimal perf impact ( ~1% of one cpu core for me ). You'll need CAVA installed to use it.
